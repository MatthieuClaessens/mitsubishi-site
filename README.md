## 📖 Overview
**Mitsubishi Lancer Evolution X Concept** is a frontend portfolio project designed to push the boundaries of UI/UX layout and motion design. Inspired by the legendary rally car, this release focuses on crafting an aggressive, immersive, and fast-paced digital experience.

> **💡 Note:** This is an independent personal project created for design and development practice, and is **not an official website** of Mitsubishi Motors.

🔗 **Live Preview:** [Explore the V1 Site](https://matthieuclaessens.github.io/mitsubishi-site/)  
🚀 **Looking for the modern evolution?** Check out the [Mitsubishi V2 (React / Next.js / TypeScript)](https://github.com/MatthieuClaessens/mitsubishi-v2) repository.

---

## 🛠️ Tech Stack & Architecture

| Component | Technology | Role |
| :--- | :--- | :--- |
| **Bundler & Dev Server** | **Vite** | Fast building and lightning-fast HMR workflow. |
| **Markup & Styling** | **HTML5 & TailwindCSS** | Responsive layout, utility-first styling, and dark theme setup. |
| **Interactivity** | **JavaScript (ES6+)** | DOM manipulation, dynamic states, and event listeners. |
| **Animation Engine** | **GSAP (GreenSock)** | Smooth transitions, scroll-triggered effects, and motion choreography. |

---

## ⚡ Key Features
* **Immersive Visual Identity:** A dark-mode first design language tailored to high-performance automotive branding.
* **Fluid Motion Design:** Advanced micro-interactions and scroll animations powered by GSAP.
* **Responsive Grid Layout:** Optimized structure ensuring seamless viewing across desktop, tablet, and mobile viewports.

## 🌐 Quick Start / Usage

To run this project locally using Vite:

```bash
# Clone the repository
git clone https://github.com/MatthieuClaessens/mitsubishi-site.git

# Navigate to the project directory
cd mitsubishi-site

# Install dependencies
npm install

# Start the local development server
npm run dev
